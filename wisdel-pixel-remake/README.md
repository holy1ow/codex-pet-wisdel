# 维什戴尔·像素重制版

银发、金瞳、红黑配色的像素重制版本。头身比例重新设计，动作幅度和节奏更清楚。

- 待机：呼吸、眨眼和轻微呆毛变化。
- 移动：朝向明确的左右交替迈步。
- 互动：抬臂挥手、蹲伏起跳、落地回到原位。
- 状态：失败反应、摊掌等待、托腮思考、扫视检查。
- 注视：顺时针 16 向姿态。

![像素重制版动画预览](../previews/wisdel-pixel-remake.gif)

## 下载与安装

[下载 ZIP 安装包](https://github.com/holy1ow/codex-pet-wisdel/raw/refs/heads/main/wisdel-pixel-remake/wisdel-pixel-remake-install.zip)

将 `pet.json` 与 `spritesheet.webp` 放入 `~/.codex/pets/wisdel-pixel-remake/`，然后在「设置 → 宠物」刷新，选择「维什戴尔·像素重制版」。Windows 默认路径及自定义 `CODEX_HOME` 的说明见 [仓库安装指南](../README.md#安装)。

安装清单使用 ID `wisdel-pixel-remake`。精灵图是 `1536 × 2288` 的 v2 无损透明 WebP，含 73 个动画 / 注视帧及一张静止回退图。
