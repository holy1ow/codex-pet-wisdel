# 维什戴尔·原比例特色版

保留原图的大头、短身和短腿比例，以及银发、圆形金瞳、红黑装饰和胸前包裹结构。

- `Move` 参考：短腿交替迈步，强化左右朝向。
- `Interact` 参考：眯眼、猫嘴笑、抱臂晃头，融入工作和检查状态。
- `Special` 参考：怒目、小金瞳、张嘴露齿的夸张颜艺，融入失败反应，再逐步泄气恢复。
- 补充动作：抬手挥动、真实腾空与落地、摊掌歪头询问。
- 注视：顺时针 16 向姿态。

![原比例特色版动画预览](../previews/wisdel-pixel-original.gif)

## 下载与安装

[下载 ZIP 安装包](https://github.com/holy1ow/codex-pet-wisdel/raw/refs/heads/main/wisdel-pixel-original/wisdel-pixel-original-install.zip)

将 `pet.json` 与 `spritesheet.webp` 放入 `~/.codex/pets/wisdel-pixel-original/`，然后在「设置 → 宠物」刷新，选择「维什戴尔·原比例特色版」。Windows 默认路径及自定义 `CODEX_HOME` 的说明见 [仓库安装指南](../README.md#安装)。

安装清单使用 ID `wisdel-pixel-original`。精灵图是 `1536 × 2288` 的 v2 无损透明 WebP，含 73 个动画 / 注视帧及一张静止回退图。
